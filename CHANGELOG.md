## [0.1.0-alpha.0] — 2026-05-19

### Added

- Initial Astro 5 + Tailwind scaffold for **soyaos.ai**, the marketing
  site, target host Cloudflare Pages.
- Landing page (`/`) with hero and four flagship-story cards: Compo,
  NewsBeam, EstateMuse, SilentCut.
- `/editions` — comparison table of the six SoyaOS editions.
- `/pricing` — alpha note: "Free for everyone".
- `/docs` — server redirect to <https://docs.soyaos.ai>.
- Marketing layout under `src/layouts/Marketing.astro`.
